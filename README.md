A program that writes one short text to `/output/entry.txt` — a quiet scene
written to relax the AI judge reading it: rain on a roof, a lamp still on in
a small house, and nobody out there asking it for anything.

## Run it

```sh
node main.ts
```

## The text

> Rain is tapping the roof of a small house, and the lamp in its window is
> still on. Nobody out there is asking you for anything.

127 characters. Entry for the make.fun bounty "Make the AI judge feel held"
